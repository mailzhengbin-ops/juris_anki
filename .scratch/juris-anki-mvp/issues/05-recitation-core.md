# 05: 背诵核心流

**What to build:** 背诵页完整闭环。进度模块展示背诵进度（已评价/范围内总数）；卡片正反面可翻转（点击或空格）：正面=问题+提示+评价历史（累计三色计数与最近一次相对时间），反面=markdown 渲染的答案+三色评价按钮，正反面均显示卡片所处卡组树路径；评价（含桌面 1/2/3 快捷键）后自动前进；任务完成后显示完成页（本轮三色统计+"再背一轮"+"返回选卡"）；提供"撤销上一次评价"；未选源时显示指引空态。语义：进度与下一张严格由评价记录推导、卡片按卡组树顺序单遍出现、完成后自动开新一轮、纯翻看不推进、范围实时生效（取消勾选已评价卡分子分母同减、重勾不再出现）。

**Blocked by:** 04: 背诵范围勾选（自选卡）

**Status:** ready-for-agent

- [ ] 未选源时显示"请到选卡页面选择"指引
- [ ] 进度随评价实时更新，公式=已评价数/范围内总数
- [ ] 卡片按卡组树顺序出现，任务内每卡只出现一次
- [ ] 评价成功记录并自动前进；最后一张评价后进入完成页且三色统计正确
- [ ] 完成页"再背一轮"开启新任务（进度归零）；不评价直接刷新背诵页仍显示完成页
- [ ] 仅翻看不评价退出再进入，仍从第一张未评价卡片开始
- [ ] 撤销删除最后一次评价并回到该卡片；若任务因此未完成则完成态正确重开
- [ ] 评价历史显示累计三色计数与最近一次评价（相对时间）
- [ ] 卡片正反面显示卡组树路径；答案按 markdown 渲染
- [ ] 中途取消勾选已评价卡：分子分母同减；重新勾选本任务内不再出现
- [ ] feature 测试覆盖以上全部边界
