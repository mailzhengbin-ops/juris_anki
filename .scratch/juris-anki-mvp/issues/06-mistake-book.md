# 06: 错题本

**What to build:** 系统预置的错题本背诵源。卡片最新评价为"模糊/忘记"时自动进入对应子卡组（在册），评"认识"即出册、再错重新在册；错题本卡组树含"忘记""模糊"两个子卡组（按此顺序），组内卡片按原属卡组树顺序排列；卡片显示原属卡组路径+在册标签；支持范围勾选（默认全选）；错题本与自选卡是两条并行的独立任务线，切换源互不干扰进度；跨源联动：在自选卡中评"认识"的卡同时从错题本任务的未背队列消失。

**Blocked by:** 05: 背诵核心流

**Status:** ready-for-agent

- [ ] 评"模糊/忘记"的卡片立即出现在错题本对应子卡组；在册状态由最新评价派生
- [ ] 评"认识"后出册；出册后再评"模糊/忘记"重新在册
- [ ] 错题本内卡片显示原属卡组路径与在册标签
- [ ] 错题本任务与自选卡任务进度互相独立，切换后各自继续
- [ ] 在错题本中评"认识"使当前任务范围实时缩水；在自选卡中评"认识"使该卡从错题本队列消失
- [ ] 错题本支持单卡/整级勾选与全选/清空，默认全选，点选即存
- [ ] 删除卡片后其在册状态随卡片消失，历史统计不受影响
- [ ] feature 测试覆盖在册/出册/重入、并行任务、跨源联动
