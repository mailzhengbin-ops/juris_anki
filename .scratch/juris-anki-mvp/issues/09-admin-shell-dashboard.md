# 09: 管理端骨架与仪表盘

**What to build:** /admin 前缀的独立管理端：管理员中间件做权限隔离（非管理员一律 403，管理员为种子账号且唯一）；侧边栏管理布局（仪表盘/卡片管理/用户管理导航）；仪表盘展示数据类信息（网站用户数、系统卡组数）与环境类信息（PHP 版本、web 服务器及其版本、数据库及其版本、Laravel 版本）。

**Blocked by:** 02: 卡组仓库与自选卡（基础 schema）

**Status:** ready-for-agent

- [ ] 管理员可进入 /admin 仪表盘
- [ ] 普通用户访问 /admin 下任何路由得到 403，游客重定向登录
- [ ] 仪表盘展示用户数与系统卡组数且数值正确
- [ ] 仪表盘展示 PHP/web 服务器/数据库/Laravel 版本信息
- [ ] 管理布局含三处导航入口（卡片管理、用户管理为占位）
- [ ] feature 测试覆盖权限隔离与仪表盘数据
