# 03: Markdown 导入创建用户卡组

**What to build:** 用户在卡组仓库的用户卡组 tab 上传 markdown 文档，一键创建自己的用户卡组：一文档即一卡组，按三层结构生成；导入为单事务，任何校验失败整体回滚并给出带行号的精确报错；支持删除用户卡组（级联删除子卡组/卡片/范围/进度，评价记录保留）。解析器为无框架依赖的纯函数，校验规则见 spec 的 markdown 导入一节（游离文本忽略、层级违规失败、答案空失败、答案内含围栏失败、同名卡组冲突失败、≤2MB、≤2000 卡）。

**Blocked by:** 02: 卡组仓库与自选卡（基础 schema）

**Status:** ready-for-agent

- [ ] 合法文档（含游离杂行）导入成功并按三层结构建组
- [ ] 层级违规（####+、## 不在 # 之下、### 不在 ## 之下）报行号错误，不产生半成品
- [ ] 答案为空、答案内出现围栏、文档无 ###、多于一个 # 均校验失败并报行号
- [ ] 超上限（>2MB 或 >2000 卡）拒绝
- [ ] 同一用户导入同名卡组失败并提示改名
- [ ] 用户卡组 tab 展示自己的卡组并可删除（删除后其卡片从范围/错题本消失，历史统计不变）
- [ ] 解析器纯函数单测覆盖边界矩阵（唯一辅助测试缝）
- [ ] 导入端点 feature 测试覆盖成功与失败路径
