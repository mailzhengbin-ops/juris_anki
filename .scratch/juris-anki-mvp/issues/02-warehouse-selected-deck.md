# 02: 卡组仓库与自选卡（基础 schema）

**What to build:** 基础数据层与选卡页仓库闭环。三层卡组树（卡组->子卡组->卡片）与用户背诵字段（管理员标志、自选卡、当前背诵源）落库；种子创建唯一管理员（凭环境变量提供凭据）与示例系统卡组「刑法」（由示例文档导入，含两个子卡组）。登录用户在选卡页的卡组仓库模块浏览系统卡组列表（名称+卡片总数）、查看卡组详情（子卡组列表及各自卡片数）、确认后将该卡组设为自选卡（用户维度唯一）。
