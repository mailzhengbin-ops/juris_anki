# 10: 管理端-系统卡组管理

**What to build:** 管理员在卡片管理中通过 markdown 导入创建系统卡组（与用户端共用同一条解析/校验管线）；系统卡组列表与详情查看；原位编辑卡组名/子卡组名/卡片问题/答案；删除系统卡组/子卡组/卡片（带确认与影响提示）。原位编辑保持卡片身份连续，不影响用户的评价历史、错题本在册与任务进度；删除卡片后该卡从所有用户的范围与错题本中消失，评价记录保留用于统计。

**Blocked by:** 03: Markdown 导入创建用户卡组；09: 管理端骨架与仪表盘

**Status:** ready-for-agent

- [ ] 管理员导入合法文档成功创建系统卡组，校验规则与用户端一致
- [ ] 系统卡组列表与详情（子卡组/卡片）可查看
- [ ] 可原位编辑卡组名/子卡组名/问题/答案，用户端即时看到新内容
- [ ] 编辑后用户的评价历史、在册状态、任务进度不变
- [ ] 删除卡片：从所有用户范围与错题本消失，历史统计不变
- [ ] 删除卡组/子卡组/卡片均有确认与影响提示
- [ ] feature 测试覆盖导入、编辑不扰动用户侧、删除联动
