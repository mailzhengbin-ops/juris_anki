# Juris Anki -- 卡片背诵系统 MVP

Status: ready-for-agent

## Problem Statement

法律硕士考生需要大量背诵学科知识点（刑法、民法等的问题-答案对）。通用 Anki 类产品以间隔重复算法为核心，用户无法完全自主决定"今天背什么、背多少、背几遍"；而考生实际需要的是：自己圈定范围、单遍过卡、用"认识/模糊/忘记"标记掌握情况、把错题集中起来反复攻克，并在手机上随时背诵。

## Solution

构建 Juris Anki：一个无间隔重复算法、以"用户自主选择"为核心的卡片背诵系统。用户从卡组仓库（系统卡组 + 自己导入的用户卡组）选定一个"自选卡"，或在系统派生的"错题本"上，勾选背诵范围，开始单遍背诵任务（看题 -> 主动回忆 -> 翻面看答案 -> 三色评价 -> 自动下一张）；范围与进度按（用户，卡组）记忆，两个背诵源可随时切换、互不干扰；评价实时驱动错题本在册/出册；近七日统计按天分桶展示三色评价数。另含管理员后台（仪表盘、系统卡组管理、用户管理）。

## Implementation Decisions

**数据模型**
- 三层卡组树：卡组 -> 子卡组 -> 卡片（问题+答案），层级固定，卡片带顺序位；卡组归属可空用户（空=系统卡组）
- 评价是不可变追加日志（用户、卡片、所属任务、三值枚举、时间）
- 背诵范围不落全量状态：只存"取消勾选"记录（排除表），无记录即默认全选，新增卡片自动默认勾选
- 任务表记录（用户、源类型、源卡组、开始/完成时间）；"当前任务"= 该源最新未完成任务；自选卡源的任务须匹配当前自选卡
- 用户表增加：管理员标志、自选卡外键、当前背诵源枚举
- 错题本完全不落库：在册 = 每卡最新评价 ∈ {模糊, 忘记}，实时派生

**领域语义**
- 单源任务：一个任务只属于一个背诵源；自选卡与错题本是两个可并行的独立任务线
- 进度与"下一张"严格由评价记录推导，纯翻看不推进；任务从该源本范围第一张评价起算
- 完成判定 = 范围内无未评价卡片；完成后再评价自动开启新任务（进度归零）；GET 背诵页也会惰性补判完成
- 撤销 = 删除当前任务最后一条评价并重算完成态
- 实时范围语义：取消勾选已评价卡 -> 分子分母同减；重新勾选 -> 本任务内不再出现；在自选卡源评"认识"导致卡片出册后，该卡同时从错题本任务的未背队列消失
- 范围与进度按（用户，卡组）持久记忆，更换自选卡后再换回原样恢复
- 删除卡片 -> 评价记录保留（卡片外键置空），历史统计不变；错题本在册随卡片消失自然退出；删除用户级联删除其全部数据
- 管理员原位编辑系统卡组，卡片身份连续，用户侧评价/在册/进度不受影响

**markdown 导入**
- 用户卡组与管理端系统卡组共用同一条解析/校验管线；文档即卡组（#/##/### + 围栏答案）
- 校验规则：游离文本忽略（宽容解析）；层级违规（####+、## 不在 # 下等）失败；答案空失败；答案内出现围栏失败；同名卡组（同一拥有者范围内）失败；单文档 ≤2MB、≤2000 卡；单事务原子导入，失败整体回滚不留半成品

**架构与交互**
- 单一 Inertia 应用：用户端移动优先布局（移动底部 tab 导航：背诵/选卡/统计/我的；桌面顶部导航）；管理端复用侧边栏布局，独立 /admin 前缀 + 管理员中间件（非管理员 403）
- 管理员为唯一种子账号，凭环境变量提供凭据；种子同时导入示例卡组文档作为演示系统卡组
- 背诵页交互：卡片展示模块仅含正面（问题/提示/评价历史）与反面（答案）；用户评价模块独立，翻面查看答案后才出现、固定在屏幕底部（移动端位于底部 tab 上方），含三色按钮与“撤销上一次评价”；评价后自动前进；完成页含本轮三色统计与“再背一轮/返回选卡”；不提供自由回看；快捷键空格翻面，翻面后 1/2/3 三色、U 撤销
- 答案渲染引入 markdown 渲染库（react-markdown + remark-gfm，已获批准的唯一新依赖）；统计图表用纯 CSS 堆叠柱状图，不引图表库
- 路由动作经 Wayfinder 生成的前端函数调用；统计按用户浏览器时区分自然日
- 账号：Fortify 开放注册（邮箱+昵称+密码）、无邮箱验证、无密码重置（登录页保留"忘记密码"入口但提示暂未开通）；登录后落地背诵页；邮箱验证相关中间件从路由移除

## Testing Decisions

- 好测试只断言外部可观察行为（HTTP 状态/重定向/Inertia props/数据库可见状态），不断言内部实现细节，重构不破测试
- **主缝：HTTP 端点**（Pest feature 测试）。全部领域语义经端点覆盖：背诵流（评价建任务、卡组树顺序、进度、完成、再背一轮重置、取消勾选减分母、重勾不复现、撤销重开）、错题本在册/出册/重入/跨源联动、范围勾选持久与默认全选、统计口径（同日去重取末次、空日补零、时区分桶）、导入成功/失败矩阵、管理端权限（非管理员 403）与级联（编辑不动评价、删卡保统计、删用户全删）、游客重定向
- **唯一辅助缝：markdown 解析器纯函数单测**。边界矩阵大（游离文本、层级、空答案、嵌套围栏、行号报错、上限、重复结构），经 HTTP 上传端点测试不经济；解析器为无框架依赖纯函数
- Prior art：现有 Feature/Auth 测试与仪表盘测试的 Pest 风格（工厂造数 + 断言响应）
- 不为领域服务层单独开测试缝；不测前端组件内部状态

## Out of Scope

- 间隔重复调度算法与任何算法推荐
- 多源混合背诵（一个任务含多个背诵源）
- 自由回看已评价卡片 / 浏览模式
- 逐张建卡表单（卡组只能 markdown 导入创建）
- 卡组分享、协作、用户间可见性
- 封禁用户、管理员手动重置密码
- 邮箱验证、密码重置邮件链路（开发期关闭，上线前另行配置）
- 原生 App、离线支持、PWA
- 卡组/卡片版本化
- 引入图表库
