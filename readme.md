# 项目介绍
本系统（Juris Anki）是面向法律硕士考试的卡片背诵系统（类Anki类产品）

[补充建议：移动优先的响应式单栏布局（主要在手机上背题），桌面端可用；桌面快捷键：空格翻面，1/2/3=认识/模糊/忘记]

## 设计要点
### 核心理念
本系统不使用任何`间隔重复调度算法`，而采用`用户自主学习模式`，这意味着用户通过自主选择卡片来安排自己要学习什么内容，而不是算法推荐

### 工作流程
用户从背诵源中选择背诵范围加入背诵任务->开始背诵任务（看题目->主动回忆->看答案->评价背诵情况（认识、模糊、忘记）->下一张卡片）->完成本次背诵任务（背诵范围内的全部卡片背完）

### 权限设计（角色权限）
本系统一共两种权限角色：管理员（本系统只有一个管理员）和用户

### 卡组结构（卡组树）
以可展开/收起的层级列表展现，采用三层结构（卡组->子卡组->卡片），卡片挂载在子卡组上，子卡组挂载在在卡组上。卡组通常是一个学科，如刑法卡组；子卡组通常是学科下的一个章节，如绪论卡组；卡片通常章节下的一个问题，如刑法的任务卡片

### 登陆注册
身份验证使用Starter Kits提供的Laravel Fortify。

[补充建议：开放注册，不强制邮箱验证；注册字段=邮箱+昵称（必填，用于展示与用户管理搜索）+密码；登录页显示“忘记密码”入口，开发期点击提示暂未开通]


### 核心术语
+ 背诵源：是用户在自选卡卡组或错题本卡组中选择加入背诵任务的背诵范围。
    + 背诵任务内每张卡片只出现一次

+ 背诵范围：用户在卡组中勾选的卡片集合
    + 背诵范围的修改，其他卡片不受影响，且立即在背诵任务中生效
    + 每张卡片的背诵范围默认全选
    + 背诵范围支持混选
    [补充建议：实时生效的边界——取消勾选已评价的卡片，进度分子分母同减；重新勾选后该卡在本任务内不再重复出现；任务完成条件=范围内无未评价卡片。在自选卡任务中评“认识”的卡片若同时位于错题本任务的未背队列，切回错题本任务时该卡已不在队列（错题本成员随最新评价实时派生）]

+ 背诵任务：针对背诵源的当前背诵范围的一次单遍背诵过程（从评价完当前背诵范围第一张卡片起，到背诵范围内全部卡片完成）
    + 在背诵任务中，卡片固定按照卡组树顺序出现
    [补充建议：任务完成（范围内全部卡片已评价）后，再次进入该源自动开启新一轮任务，进度归零。进度与“下一张”严格由评价记录推导：仅翻看不评价不推进位置，重新进入仍从第一张未评价卡片开始]

+ 背诵进度：指的是当前背诵任务中用户已经背到第几张卡片了（计算公式为：`背诵范围`中已经完成评价的卡片数/当前背诵范围的总卡片数）
    + 用户切换背诵源后，再切回该背诵源时，仍继续之前的背诵进度

### 用户端

#### 背诵页面
+ 用户没有选择背诵源时，显示“当前您没有选择背诵源，请到选卡页面选择！”
+ 背诵任务完成后，显示 “恭喜你！当前背诵任务已完成！”
[补充建议：流程细节--评价后自动前进到下一张；最后一张评价完进入完成页（本轮三色统计 + “再背一轮”重开新任务 + “返回选卡”按钮）；不做自由回看，提供“撤销上一次评价”（防误触，撤销后回到该卡片）]

##### 背诵进度模块
+ 此模块展示背诵进度

##### 卡片展示模块
+ 每张卡片都有正面和反面，可以翻转
    + 正面内容：问题、提示（“请回忆该问题，点击屏幕显示答案”）、评价历史、
    + 反面内容：答案、卡片评价（认识/模糊/忘记）
    + 正反面内容：本卡片所处位置（卡组树路径）
    [补充建议：评价历史展示累计统计（共背 N 次：认识 x · 模糊 y · 忘记 z）与最近一次评价结果及时间，不做逐条流水]
    [补充建议：错题本中背卡时，路径显示卡片原属卡组（如“刑法/绪论”），另以标签显示在册状态（忘记/模糊）]

#### 选卡页面

> 此页面有两个模块：`当前在背`模块是可供选择的背诵源集合，由`自选卡`和`错题本`构成；`卡组仓库`模块由`系统卡组`和`用户卡组`构成

##### 当前在背模块

+ 默认选中自选卡
+ 当点击`自选卡`或`错题本`时，可以查看当前卡组的卡组树页面，在这里，用户可以通过复选框勾选背诵范围

[补充建议：点击`自选卡`或`错题本`tab 即将该源设为当前背诵源；背诵页面顶部提供两源快速切换]

[补充建议：勾选交互--点选即保存（无确认按钮，实时落库）；三层联动复选框（卡片级 + 子卡组级三态 + 卡组级三态）；源顶部提供全选/清空快捷按钮]

**自选卡**：

+ 自选卡是用户从卡组仓库中选择的一个卡组
    + 自选卡中只能存在一个卡组
    [补充建议：范围勾选与任务进度按（用户，卡组）持久记忆；更换自选卡后再换回，勾选与进度原样恢复]


**错题本**：

这是系统预先设定的卡组，其中包含两个子卡组：“忘记”和“模糊”
+ 用户最新一次评价记录为“忘记”或者“模糊”的卡片都会进入此卡组对应的子卡组内（最新为“忘记”或“模糊”即在册）
+ 当用户评价“认识”后，就将其移出此卡组；如果移出后又被评价为“忘记”或“模糊”，则重新进入此卡组对应的子卡组内

[补充建议：错题本内两个子卡组顺序为“忘记”、“模糊”；子卡组内卡片按其原属卡组树顺序排列]

##### 卡组仓库模块
这是用户选择自选卡的地方
+ 本模块采用两栏布局
+ 用户点击卡组仓库的某个卡组后，打开卡组详情页，详情页面包含：卡组名字，卡片数，确认选择该卡片（确认后该卡组成为自选卡）。

[补充建议：两栏布局--左栏卡组列表（`系统卡组`/`用户卡组`二级 tab，每项显示卡组名+卡片总数）；右栏选中卡组详情（卡组名、卡片总数、子卡组列表及各自卡片数、“设为自选卡”按钮；用户卡组另含删除按钮带确认）；移动端折叠为列表页->详情页两级导航]

**系统卡组**：

系统内置的卡组，由管理员在管理端的卡片管理中创建。

[补充建议：管理员对系统卡组原位编辑（卡片按 ID 保持身份），不影响用户评价历史、错题本在册与任务进度；删除卡片时，该卡从所有用户的范围与错题本中消失，评价记录保留用于统计]

**用户卡组**：
+ 此页面展示用户自己创建的卡组
+ 提供创建卡组按钮，点击后可以一键导入
[补充建议：删除用户卡组时，级联删除其子卡组、卡片、范围勾选与任务进度；评价记录保留（历史统计不受影响）；错题本在册成员随卡片删除自然退出]

[补充建议：导入校验细则--标题行与代码块之外的游离文本忽略（宽容解析）；答案代码块内出现```则校验失败并指出位置；同一子卡组内问题标题重复允许；同名卡组冲突（同一用户/系统内）校验失败提示改名；导入为单事务，失败整体回滚；规模上限：单文档≤2MB、≤2000张卡片]

```
卡组只能通过markdown格式的文档导入来创建，导入后按照卡组结构（卡组树）创建卡组；文档规范如下，参考`card_template.md`：

+ 一文档即为一个卡组
+ 文档内只能一个 #（卡组）；至少一个 ##（子卡组）；至少一个 ###（卡片的问题），其后两个```之间为答案（不允许为空，按照markdown格式解析给用户）
+ 其中 ## 只能出现在 # 之下；### 只能出现在 ## 之下；#### 及更深层级直接校验失败

```

#### 统计页面

【当前用户近七日（包含今天，按用户所在时区划分自然日；共展示最近七个自然日，即使当天没有评价也显示为 0）按天分桶，每天展示“认识”“模糊”“忘记”三个数。统计包含用户在所有背诵源中的评价记录；同一张卡片同一天被评价多次时只计一次，并归入当天最后一次评价对应的类别。】

[补充建议：呈现形式--近七日堆叠柱状图（认识/模糊/忘记三色），每日数值可读，底部显示本周三色合计；无数据日期显示为 0]
